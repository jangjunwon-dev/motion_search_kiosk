## 시연 시나리오 (라이브 3분)

`training/scenarios/basic.txt` 와 같은 순서 — 시연 자체가 성능평가 시나리오와 일치하도록.

1. 대기 화면에서 ☝️ 손 들기 → 커서 등장, 홈 화면
2. ☝️ 로 "건물 안내" 가리키고 ✊ → 목록
3. ✋ 왼쪽으로 쓸기 → 다음 페이지, 오른쪽으로 → 이전 페이지
4. ☝️ 카드 위에 1.5초 가만히 → dwell 클릭으로 상세 (두 가지 클릭 방식 보여주기)
5. 👍 유지 → QR 팝업, 👎 → 닫기, 👎 → 목록
6. ✌️ → 처음 화면
7. (보너스) 뒤에서 다른 사람이 손을 흔들어도 **가까운 사람 손만** 따라감 → 활성 손 선택 시연

**시연 준비물**: 노트북 + 외장 웹캠(삼각대), 단색 배경 가능하면 좋음, 조명 확인, 녹화 영상(`시연영상/`) 바탕화면에, `python -m kiosk` 미리 실행해 두기

## 한계점·개선 방향 (초안 — 실제 겪은 것으로 교체)

| 한계 | 원인 | 개선 방향 |
|---|---|---|
| 역광·어두운 곳에서 누락 | 학습 데이터 조명 분포 | 저조도 증강, 현장 데이터 추가 학습 |
| 비슷한 손 모양 혼동 (one ↔ peace 등) | 정적 이미지 단일 프레임 판단 | 다수결로 완화, 클래스별 conf 임계값 분리 |
| 여러 사람이 동시에 손을 듦 | 활성 손 = 가장 큰 손 규칙 | 사람(person) 탐지 + 얼굴 방향으로 "사용자" 고정 |
| 스와이프가 정적 탐지의 조합 | 동적 제스처 전용 모델 아님 | 궤적 기반 시계열 분류(소형 GRU 등) |
| CPU 에서 FPS 낮음 | 모델 크기 | ONNX/OpenVINO 변환, 입력 크기 416 |
