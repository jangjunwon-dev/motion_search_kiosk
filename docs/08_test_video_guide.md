# 08. 손동작 테스트 영상 촬영 가이드 (둘 다)

> **목적**: 모델이 나오면 이 영상을 `python -m kiosk --video` 로 반복 재생해서
> ① 기준값(`configs/app.yaml`) 튜닝, ② **명령 인식률** 측정(발표 성능평가 자료)에 씁니다.
> 손동작만 찍는 거라 **모델 없이 지금 찍어 둘 수 있습니다.**

| 항목 | 내용 |
|---|---|
| 누가 | 장준원, 성민수 각자 1개씩 |
| 길이 | 약 1분 30초 |
| 파일명 | `손동작_테스트_장준원.mp4`, `손동작_테스트_성민수.mp4` |
| 올릴 곳 | 공유 드라이브 `motion_search_kiosk/시연영상/테스트영상/` |
| ⚠️ 주의 | **테스트 전용 — 학습(train)에 절대 넣지 않기** (시험 문제를 보고 공부한 셈 → 점수가 부풀려짐). 학습용 사진이 필요하면 따로 새로 찍기 |

> 발표 때 보여줄 **시연 영상**(키오스크로 실제 주문하는 화면 녹화)은 이것과 별개로, 완성 후(12/09~12/13) `시연영상/` 에 찍습니다.

## 1. 준비
1. Windows **시작 → "카메라" 앱** → 오른쪽 버튼을 **동영상(🎥)** 으로
2. **키오스크를 쓸 자세**로 앉기 — 카메라에서 **50cm~1m**
3. 방 불 켜기, **창문을 등지지 않기** (역광이면 손이 어둡게 찍힘)
4. 손은 **가슴~얼굴 높이**, **손바닥이 카메라 쪽**

## 2. 촬영 순서 (그대로 따라 하기)

동작 사이에는 **손을 내려서 1초 쉬기** → 동작이 섞이지 않고, 나중에 횟수 세기 쉬움.

| 순서 | 손동작 | 어떻게 | 반복 |
|---|---|---|---|
| 0 | (손 없음) | 손 내리고 가만히 3초 | 1 |
| 1 | ☝️ 가리키기 | 검지만 펴고 천천히 **왼쪽 → 오른쪽 → 위 → 아래** (5초) | 1 |
| 2 | ☝️ → ✊ 클릭 | 검지로 2초 가리키다가 **주먹 쥐고 1초** → 손 내리기 | 3 |
| 3 | ✋ 넘기기 ← | 손바닥 펴고 **오른쪽 → 왼쪽으로 한 번에 쓸기** (0.5초 정도로 빠르게) | 3 |
| 4 | ✋ 넘기기 → | 손바닥 펴고 **왼쪽 → 오른쪽으로 쓸기** | 3 |
| 5 | 👍 확인 | 엄지 올리고 **2초 유지** | 3 |
| 6 | 👎 뒤로 | 엄지 내리고 **2초 유지** | 3 |
| 7 | ✌️ 처음으로 | 브이 하고 **2초 유지** | 3 |
| 8 | (손 없음) | 손 내리고 가만히 3초 | 1 |

- **3번씩 하는 이유**: "3번 중 몇 번 인식됐나" = 명령 인식률
- **2초씩 유지하는 이유**: 👍👎✌️ 는 0.7초 유지해야 실행 → 넉넉하게
- **처음·끝 손 없는 구간**: 손이 없는데 명령이 실행되는지(오발동) 확인용

## 3. 각 손동작의 의미 (요약)

| 손동작 | 모델 클래스 | 키오스크 명령 | 판정 기준 (`configs/app.yaml`) |
|---|---|---|---|
| ☝️ 검지 | `one` | 커서 이동 | 박스 위쪽(검지 끝) 위치 → 화면 좌표 (좌우 반전) |
| ☝️ → ✊ | `fist` | 클릭 | 가리키다 0.8초 안에 주먹 (`click_window_s`) |
| ✋ 손바닥 이동 | `palm` | 페이지 넘기기 | 0.45초 안에 화면폭 18% 이상 가로 이동 (`swipe_window_s`, `swipe_min_dx`) |
| 👍 | `like` | 확인 (담기·주문·닫기) | 0.7초 유지 (`hold_s`) |
| 👎 | `dislike` | 뒤로 | 0.7초 유지 |
| ✌️ | `peace` | 처음으로 | 0.7초 유지 |

자세한 원리: [06_how_it_works.md](06_how_it_works.md)

## 4. 모델이 나온 뒤 테스트하는 법

```powershell
# 드라이브에서 영상을 받아 저장소 videos/ 폴더에 넣기 (videos/ 와 *.mp4 는 Git 에 안 올라감)
mkdir videos
python -m kiosk --video videos\손동작_테스트_장준원.mp4 --no-loop
python -m kiosk --video videos\손동작_테스트_성민수.mp4 --no-loop
```

- 재생이 끝나면 `logs/events_*.csv` 에 실행된 명령이 기록됨 → 아래 기대값과 비교
- **기대 명령 (이 영상 기준)**: `click` 3, `swipe left` 3, `swipe right` 3, `confirm` 3, `back` 3, `home` 3, 그 외 명령 0
- 사람별로 따로 돌려서 결과를 비교 → `docs/experiments.md` 에 기록 (측정한 숫자만)
